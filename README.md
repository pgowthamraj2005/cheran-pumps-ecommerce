# Cheran Pumps - Bore Motors & Pumps Website

Scaffolded Django project for the Cheran Pumps storefront. Uses SQLite by default for local development. Configure MySQL in `cheran_pumps/settings.py` when ready.

Quick start:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
